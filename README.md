# FoundryVTT WARDEN system

A work in progress FoundryVTT system for the WARDEN TTRPG.

## Installation

Go to "Install System" in Foundry, paste [this](https://raw.githubusercontent.com/Lunar-Dawn/WARDEN/refs/heads/main/system.json) link into the "Manifest URL" field and press install.
A real listing in Foundry's install dialogue will be there soon™

## Setup

Simply clone the repo and run `npm install`

This sets up a pre-commit hook to run the formatter on all files to unify formatting.
There's also a `npm run format` command to run it manually,
it's also recommended to set up format-on-save in your editor for convenience.
